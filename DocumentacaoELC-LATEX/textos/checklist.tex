\begin{tabularx}{\linewidth}{ r X } 
    \textbf{RF - Realizar login no sistema} \\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Nome: } & Login \\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Descrição: } & O sistema deve permitir que um usuário devidamente
    cadastrado realize login no sistema, bastando para isso apenas que ele digite corretamente seu login e sua senha.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Atores: } & Administrador, aluno, professor e monitor (qualquer
    usuário cadastrado)\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Prioridade: } & Essencial\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Entradas e Pré-condições: } & Usuário informar login e senha ao
    sistema.\\ 
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Saídas e Pós-condições: } & Usuário informar login e senha ao
    sistema.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo de Eventos}
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo Principal: } & 1.   Um usuário do sistema informa os dados
    necessários para a realização do login: Login; Senha; Clica no botão Entrar.
    2.   O sistema verifica a validade do login e da senha do usuário; 3.   Se o login e a senha corresponderem a algum usuário do sistema, o sistema leva o usuário para o seu Página inicial (Home).\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo secundário 1: } & No fluxo principal 2, se o login e/ou a
    senha forem inválidas (não correspondam a valores cadastrados no sistema), o
    sistema exibe uma mensagem informando que o login e/ou a senha é inválido,
    voltando ao passo 1. \\
\end{tabularx}


\begin{tabularx}{\linewidth}{ r X } 
    \textbf{RF - Alterar Senha} \\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Nome: } & Alterar senha \\

\begin{tabularx}{\linewidth}{ r X }
    \textbf{Descrição: } & O sistema deve permitir que um usuário devidamente
    cadastrado modifique sua senha, bastando para isso apenas que ele digite corretamente seu login, sua senha antiga e a nova senha desejada.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Atores: } & Administrador, aluno, professor e monitor (qualquer
    usuário cadastrado)\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Prioridade: } & Secundária\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Entradas e Pré-condições: } & Usuário clicar no botão Alterar Senha, informar login, senha antiga e a nova senha ao sistema.\\ 
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Saídas e Pós-condições: } & Mensagem: ''Senha alterada com
    sucesso.''. Senha do usuário alterada no sistema.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo de Eventos}
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo Principal: } & 1. Um usuário do sistema clica no botão Alterar
    Senha, na tela de alteração de senha, ele informa: •	Login; •	Senha antiga;
    •	Nova senha; •	Clica no botão Alterar Senha. 2.   O sistema verifica a
    validade do login e da senha do usuário; 3.   O sistema altera a senha do
    usuário pela senha informada em Nova senha; 4.  O sistema emite a mensagem:
    ''Senha alterada com sucesso.''
    \\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo secundário 1: } & No fluxo principal 2, se o login e/ou a
    senha forem inválidas (não correspondam a valores cadastrados no sistema), o sistema exibe uma mensagem informando que o login e/ou a senha é inválido, voltando ao passo 1. \\
\end{tabularx}


\begin{tabularx}{\linewidth}{ r X } 
    \textbf{RF- Cadastro de alunos} \\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Nome: } & Cadastro de Aluno\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Descrição: } & O sistema deve permitir que o administrador do sistema, o monitor ou o professor cadastre um novo aluno em seu banco de dados. Para efetuar esse cadastro serão necessários apenas informar ao sistema o nome, login e o email do aluno a ser cadastrado. Uma mensagem deve ser exibida caso o aluno já esteja cadastrado.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Atores: } & Administrador do Sistema, Professor ou Monitor\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Prioridade: } & Essencial\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Entradas e Pré-condições: } & Administrador, Professor ou Monitor ter efetuado login no sistema\\ 
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Saídas e Pós-condições: } & O aluno cadastrado no banco de dados do sistema.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo de Eventos}
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo Principal: } & 1.	Ao entrar na sua página inicial (Home), ele seleciona o menu Controle de Acesso, Cadastros, aba Usuário, Grupo Aluno.  2.	Ele informa os dados do aluno necessários para a realização do cadastro: •	Nome; •	Login; •	Email. •	Opcionalmente pode ser informada uma senha para o aluno, caso nada seja informado, o sistema gera uma senha para o aluno automaticamente. 3.   O sistema verifica se o aluno já está cadastrado no sistema; 4.   O sistema verifica se o email informado já existe no sistema; 5.   O sistema armazena os dados do aluno no banco de dados e informa que o cadastro foi realizado com sucesso.
\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo secundário 1: } &  No fluxo principal 2, se o aluno já estiver cadastrado no sistema (seu login já existir no sistema) o sistema exibe uma mensagem informando o ocorrido e retorna ao passo 1.\\
\end{tabularx}
\begin{tabularx}{\linewidth}{ r X }
    \textbf{Fluxo secundário 2: } &  No fluxo principal 3, se o email já estiver cadastrado, o sistema exibe uma mensagem informando o ocorrido e retorna ao passo 1.\\
\end{tabularx}
